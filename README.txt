Warcats website (static files, no build step)

Upload everything in this folder to the ROOT of playwarcats.com, keeping the folders:
  index.html            home page
  support/index.html    https://playwarcats.com/support/
  privacy/index.html    https://playwarcats.com/privacy/
  terms/index.html      https://playwarcats.com/terms/
  delete-account/index.html   https://playwarcats.com/delete-account/   <- use this link in Google Play Console
  css/  js/  img/  fonts/  favicon.svg

Fonts are hosted here (no Google Fonts request). Big Shoulders Display and Hanken Grotesk are open-source (SIL OFL).
When the Google Play listing exists, add a button linking to it in index.html (search for "When the Google Play listing exists").
